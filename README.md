# TYPE BREAKERS

日本語の文章をローマ字で入力して、奥から迫るモンスターを撃破するブラウザ向けタイピングアクションです。

## 今すぐ遊ぶ

公開版はこちらです：<https://kuze-sorata.github.io/type-breakers/>

## 起動

```bash
npm install
npm run dev
```

ブラウザで表示されたローカルURLを開いてください。検証環境では `npm run build` で本番ビルド、`npm test` で単体テストを実行できます。

## 操作

- タイトル画面でモードと難易度を選び、「戦闘開始」を押す
- 表示された日本語の文章をローマ字で入力する
- 正しいキー入力で攻撃、全文入力でフィニッシュブロー
- `Esc` または「一時停止」でポーズ／再開
- タイトル画面の音声ボタンで生成音をミュート

## 技術構成

- TypeScript + Vite
- Canvas 2D：戦闘アリーナ、敵、遠近感、攻撃、パーティクル
- DOM/CSS：メニュー、HUD、入力ガイド、ポーズ、リザルト
- Web Audio API：入力・ミス・撃破・ダメージ・クリア音
- localStorage：ミュート設定とモード別ハイスコア

## 既知の問題・改善候補

- 音声はWeb Audio API生成音のため、音楽用の長尺BGMは未収録。
- 初期版はキーボード操作を主対象とし、スマートフォンのタッチ操作は対象外。
- ボスごとの専用攻撃パターンや敵種別の増加は次の拡張候補。
